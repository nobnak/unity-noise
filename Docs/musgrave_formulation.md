# Musgrave Texture 数式整理（Blender準拠）

## 概要

Musgrave Texture は、複数スケールの Perlin ノイズを組み合わせた
**フラクタルノイズ**であり、タイプごとに加算・乗算・非線形変換で合成される。\
Blender公式ドキュメントでも「複数スケールのノイズを組み合わせる」と明記されている。

------------------------------------------------------------------------

## 共通パラメータ（Blender定義）

-   Scale: 入力座標のスケール
-   Detail: ノイズの重ね回数（オクターブ数）
-   Dimension: 各オクターブの振幅減衰（大きいほど高周波が弱い）
-   Lacunarity: 各オクターブのスケール倍率（指数的に増加）

------------------------------------------------------------------------

## 数式定義

入力: x ∈ R\^n

### スケール

x0 = Scale \* x

### オクターブ

N = floor(Detail) r = fract(Detail)

### 周波数

f_i = Lacunarity\^i

### 振幅

a_i = Lacunarity\^(-i \* Dimension)

------------------------------------------------------------------------

## 基本形（fBm）

f(x) = Σ\_{i=0}\^{N-1} a_i \* noise(x0 \* f_i)

部分オクターブ: f(x) += r \* a_N \* noise(x0 \* f_N)

------------------------------------------------------------------------

## タイプ別定義

### 1. fBm

単純加算

------------------------------------------------------------------------

### 2. Multifractal

f(x) = Π (1 + a_i \* noise(x0 \* f_i))

------------------------------------------------------------------------

### 3. Ridged Multifractal

r_i = (1 - \|noise(x0 \* f_i)\|)\^2\
f(x) = Σ a_i \* r_i

------------------------------------------------------------------------

### 4. Hybrid Multifractal

f = noise(x0) w = f

for i: s = noise(x0 \* f_i) f += w \* a_i \* s w \*= s

------------------------------------------------------------------------

### 5. Heterogeneous Terrain

f = noise(x0)

for i: f += a_i \* noise(x0 \* f_i) \* f

------------------------------------------------------------------------

## 検証結果（ドキュメント一致）

-   Musgrave は「複数スケールのノイズの合成」 → 一致
-   Detail は「ノイズの重ね回数」 → N に対応
-   Lacunarity は「各層のスケール倍率」 → f_i に一致
-   Dimension は「高周波の強度を減衰」 → a_i に一致
-   タイプ差は「加算・乗算・非線形」 → 数式と一致

------------------------------------------------------------------------

## 結論

Blender Musgrave Texture は次の形式に還元できる：

Musgrave(x) = Σ a_i \* noise(x \* f_i) + 非線形結合

すなわち：

-   基本は fBm
-   タイプごとの差は「合成方法」の違いのみ
